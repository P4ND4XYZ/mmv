# エラーログ

[全体像に戻る](../index.md)

## 目的と位置づけ

Mermaid図の生成失敗やLua設定の読み込み・実行・検証の失敗について、本文の閲覧を妨げずに原因を確認できるようにします。

## 記録内容と画面表示

- Mermaidの生成失敗時は、発生日時、対象ファイル、図の位置、失敗理由を記録する。
- Lua設定の読み込み・実行・検証に失敗した場合は、設定ファイルのパスと原因を記録する。下部入力行には短い通知を表示し、標準設定で閲覧を継続する。詳細は[表示・配色設定](display-settings.md#設定に失敗した場合)を参照する。
- Markdown本文全体は記録しない。
- 同じエラーが繰り返し大量に記録されないようにする。
- 失敗した図のソースコードやエラー詳細は、本文内・下部入力行・ダイアログに表示しない。本文と他の図の表示は継続する。

## 保存先とローテーション

保存先は`%LOCALAPPDATA%\my-markdown-viewer\logs\viewer.log`とする。

- 容量ベースのローテーションとし、1ファイルの上限を5 MiB、バックアップを3世代とする。
- 上限に達したら現在のログをバックアップへ移し、新しい`viewer.log`へ記録する。最古のバックアップは削除する。
- バックアップ名は`viewer.log.1`、`viewer.log.2`、`viewer.log.3`とし、`.1`を直前、`.3`を最古とする。
- 現行を含む4ファイルで、合計容量は約20 MiBとする。
- 日付によるローテーションは行わない。容量・世代数は固定設定とする。

## ログを書き込めない場合

ログの作成・書き込みができない場合も閲覧を継続し、標準エラー出力へ出す。ログの失敗を理由にアプリを終了しない。

## 受け入れ条件

- [ ] 図の生成失敗時に、画面へエラー詳細を出さず、指定の保存先へ原因を記録する。
- [ ] Lua設定の失敗時は、下部入力行に短い通知を表示し、同じログへ設定ファイルのパスと原因を記録する。
- [ ] 容量上限に応じてバックアップを3世代まで残し、最古のログを削除する。
- [ ] 保存先へ書き込めなくても閲覧を続けられ、標準エラー出力へ記録する。
