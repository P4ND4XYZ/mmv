# スクロールと先頭・末尾への移動

[全体像に戻る](../index.md)

## 目的と位置づけ

Vimライクなキー操作で、文書内の閲覧位置を移動できるようにします。

## 要件

| キー | 操作 |
|---|---|
| `j` / `k` | 下／上へ、表示上の本文1行程度の距離をスクロール |
| `Ctrl+d` / `Ctrl+u` | 下／上へ半ページ移動 |
| `Ctrl+f` / `Ctrl+b` | 下／上へ1ページ移動 |
| `gg` / `G` | ファイル先頭／末尾へ移動 |

`j` / `k`の移動量はMarkdownソースの行数では数えない。表や画像の位置でも、表示上の距離として扱う。
