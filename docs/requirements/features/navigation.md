# スクロールと先頭・末尾への移動

[全体像に戻る](../index.md)

## 目的と位置づけ

Vimライクなキー操作で、文書内の閲覧位置を移動できるようにします。

## 要件

次のキー操作はNormalモードで有効とする。Search・Commandモードでは本文操作として実行しない。モードの切り替えは[画面と操作モード](viewer-ui.md)を参照する。

| キー | 操作 |
|---|---|
| `j` / `k` | 下／上へ、表示上の本文1行程度の距離をスクロール |
| `Ctrl+d` / `Ctrl+u` | 下／上へ半ページ移動 |
| `Ctrl+f` / `Ctrl+b` | 下／上へ1ページ移動 |
| `gg` / `G` | ファイル先頭／末尾へ移動 |

PDFでは本文フォーカスのNormalで`j` / `k`を40論理pxの小刻み移動とし、半ページ／1ページは本文の表示領域（viewport）の半分／全体を指す。PDFのページ境界へのジャンプではなく、移動後は先頭・末尾の有効範囲に収める。PDFにMarkdownのソース行の概念は適用しない。初期表示の幅合わせとズームは[PDF表示](pdf-viewing.md)に従う。

`j` / `k`の移動量はMarkdownソースの行数では数えない。表や画像の位置でも、表示上の距離として扱う。

マウスホイールによる本文スクロールにも対応する。
