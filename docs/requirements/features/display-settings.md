# 表示・配色設定

[全体像に戻る](../index.md)

## 目的と位置づけ

利用者のLua設定で本文領域の配置・最大幅と配色、ファイルツリーの初期表示とルート判定マーカーを指定し、読みやすい表示でMarkdownを閲覧できるようにします。

## 基本の流れ

1. 必要に応じて`%LOCALAPPDATA%\mmv\init.lua`を作成し、表示・配色を設定する。
2. ビューアーを起動すると設定を読み込み、本文とUIに適用する。設定ファイルがなければ標準設定で起動する。
3. 設定を変更した場合は、ビューアーを終了して再起動する。

## 設定ファイルの読み込み

- 読み込み先はユーザー単位の`%LOCALAPPDATA%\mmv\init.lua`とする。
- 閲覧するMarkdownの隣にある設定など、文書側のLuaファイルは自動実行しない。
- 設定の読み込みはビューアー起動時に行う。起動済みビューアーへのCLI操作やMarkdownの再読み込みでは、設定を再読み込みしない。
- 設定変更の自動反映、設定再読み込みコマンド、表示・配色を指定するCLIオプション、`:set`は対象外とする。

## Lua API

[ファイルツリー](file-tree.md)の起動時の表示／非表示は`tree.visible`で指定する。ルート判定マーカーは`tree.root_markers`で指定する。

`require("mmv")`で設定APIを取得する。表示・配色とツリー設定を対象とし、キーマップや独自コマンドの登録APIは提供しない。

```lua
local mmv = require("mmv")

mmv.setup({
  view = {
    position = "center",
    max_width = 960,
  },
  colorscheme = "dark",
  tree = {
    visible = false,
    root_markers = { ".marksman.toml", ".git" },
  },
})

mmv.set_hl("Normal", {
  fg = "#cdd6f4",
  bg = "#1e1e2e",
})

mmv.set_hl("Search", {
  bg = "#665c28",
})

mmv.set_hl("SearchCurrent", {
  bg = "#b57614",
})
```

### `mmv.setup(options)`

表示設定と標準カラースキームを指定する。省略した設定には、次の初期値を使う。

| 設定 | 値と意味 | 初期値 |
|---|---|---|
| `view.position` | `"center"`は本文領域を横方向に中央配置、`"left"`は左側に配置する | `"center"` |
| `view.max_width` | 本文領域の最大幅。単位は論理pxで、左右の外側余白は含めない。正の有限数を指定する | `960` |
| `colorscheme` | 標準カラースキームの`"dark"`または`"light"`を選ぶ | `"dark"` |
| `tree.visible` | 起動時にツリーを表示するかをbooleanで指定する | `false` |
| `tree.root_markers` | ルート判定に使う直下名の文字列配列。指定時は既定配列を置換する | `{ ".marksman.toml", ".git" }` |

- 論理pxによる幅はWindowsの表示倍率に追従する。
- `tree.visible`にかかわらず初期フォーカスは本文とする。起動後の表示切替はLuaへ書き戻さず、再起動時は設定値へ戻る。ツリー幅の設定・保存やツリー専用Lua配色APIは追加しない。
- 本文領域の配置と文字自体の配置は区別する。`view.position`にかかわらず、通常の本文の文字は左詰めとする。
- `"left"`でも最大幅を維持する。ウィンドウが狭い場合の振る舞いは[画面と操作モード](viewer-ui.md#本文領域の配置)を参照する。
- OSのテーマへの自動追従、外部カラースキームファイルの読み込み、Neovim用カラースキームとの互換性は対象外とする。

### ルート判定マーカー

- `tree.root_markers`を省略した場合は`{ ".marksman.toml", ".git" }`を使う。指定時は既定値へ追加せず、配列全体を置換する。
- 文書の親から祖先へ探索し、いずれかのマーカーがある最寄りのフォルダーを採用する。配列順による優先順位は設けない。見つからなければ文書の親を使う。
- マーカーはファイル・ディレクトリの両方を許可し、内容は読まない。空配列`{}`では探索せず、文書の親を使う。
- 名前はフォルダー直下の名前だけを許可する。空文字、パス区切り（`/`・`\`）、`.`、`..`は設定エラーとする。
- 1から始まる連続した整数添字の文字列配列だけを受け付ける。途中の欠番、文字列キー・非整数キー、文字列以外の要素は設定エラーとする。
- 変更は他の設定と同じく再起動で反映する。不正値では設定を部分適用せず、[設定に失敗した場合](#設定に失敗した場合)の全体復帰・通知・ログの規則に従う。
- マーカー探索がアクセス拒否になった場合の暫定ルートと画面表示は[ファイルツリー](file-tree.md#アクセスできない場合)に従う。

### `mmv.set_hl(name, attributes)`

標準カラースキームに対し、用途別の配色グループの属性を上書きする。

- `attributes`には文字色の`fg`と背景色の`bg`を指定できる。ただし`Search`・`SearchCurrent`は`bg`のみ、`Border`は線色を指定する`fg`のみを受け付ける。これらのグループに対応しない属性を指定した場合は設定エラーとする。色は`"#RRGGBB"`形式とする。
- 指定しない属性は、選択した標準カラースキームの値を引き継ぐ。
- 同じグループを複数回指定した場合は、指定された属性ごとに後の値を優先する。後の呼び出しで省略した属性については、それまでの上書きを維持する。
- 文字装飾や配色グループ間の参照を指定する属性は提供しない。

| グループ | 対象 |
|---|---|
| `Normal` | 基本の文字色と背景色 |
| `Border` | UIの境界線 |
| `Search` | 現在選択中ではない検索一致 |
| `SearchCurrent` | 現在選択中の検索一致 |
| `StatusLine` | 下部の状態行 |
| `CommandLine` | 下部の入力行 |
| `ModeNormal` | NORMALのモード欄 |
| `ModeSearch` | SEARCHのモード欄 |
| `ModeCommand` | COMMANDのモード欄 |
| `Heading1`〜`Heading6` | 各レベルの見出し |
| `Link` | 本文のリンク |
| `CodeBlock` | コードブロックの基本色と背景色 |
| `Quote` | 引用 |
| `Panel` | 共通の選択パネル |
| `PanelSelected` | 選択パネルの選択中の候補 |
| `Error` | エラー通知 |
| `Warning` | 警告通知 |

### 配色の対象範囲

- 本文・見出し・リンク・引用・コード背景・検索一致・下部UI・選択パネル・通知を対象とする。
- コードのシンタックスハイライトは、選択した標準カラースキームに合わせる。トークン単位のLua設定は対象外とする。
- `Link.bg`はMarkdown記法のリンクの表示テキストに適用する。HTMLブロック内のリンクは対象外とし、従来の文字色とクリック操作は維持する。リンク内の画像自体には背景を描かない。
- Mermaid図内の配色と画像の色は変更しない。

## 設定に失敗した場合

- ファイルが存在しない場合はエラーにせず、標準設定を使う。
- ファイルの読み込み、Luaの実行、設定値の検証に失敗した場合は、設定を部分適用しない。表示設定・標準カラースキーム・配色上書きのすべてを標準設定に戻して起動し、閲覧を継続する。
- 未知の設定名・配色グループ名・属性名、未対応の文字列、不正な型・色・数値は設定エラーとする。
- 設定エラーは下部入力行に短い通知を表示し、設定ファイルのパスと原因を既存の`viewer.log`へ記録する。保存先と書き込み失敗時の扱いは[エラーログ](logging.md)に従う。

## 受け入れ条件

- [ ] 設定ファイルがない場合、本文領域の中央配置・最大幅960論理px・`"dark"`・ツリー非表示で起動する。
- [ ] `tree.visible`のtrue／falseで初期表示を指定でき、初期フォーカスは本文となる。不正型では設定全体を標準値へ戻す。
- [ ] `tree.root_markers`の省略・置換・空配列でルート探索が仕様どおり変わり、配列順ではなく最寄りのマーカーを優先する。
- [ ] マーカーの不正な名前・配列形式・要素型を設定エラーとし、設定全体を標準値へ戻して通知・ログを残す。
- [ ] Lua設定で本文領域の配置と最大幅を変更でき、通常の本文は左詰めを維持する。
- [ ] `"dark"`と`"light"`を選択でき、シンタックスハイライトも選択に合わせて変わる。
- [ ] 各配色グループで対応する`fg`・`bg`を上書きでき、省略属性の継承と、同一グループへの後の属性指定の優先が機能する。非対応属性は設定エラーとする。
- [ ] 設定変更はビューアーの再起動後に反映し、文書の再読み込みやCLI操作では反映しない。
- [ ] 文書の隣に置かれたLua設定は自動実行しない。
- [ ] 実行・検証の途中まで有効な設定があっても、設定エラー時は全体が標準設定へ戻り、通知とログを残して閲覧を継続する。
