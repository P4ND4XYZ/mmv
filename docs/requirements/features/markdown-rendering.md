# Markdown描画

[全体像に戻る](../index.md)

## 目的と位置づけ

Markdownの本文、表、コード、画像などを、整形された状態で閲覧できるようにします。

## 要件

次の要素を表示する。

- 見出し、段落、箇条書き、引用、リンク。
- 表、チェックリスト。チェックリストは閲覧対象であり、ファイルを書き換えない。
- コードブロックとシンタックスハイライト。
- ローカル画像とWeb上の画像。
- Mermaid図。詳細は[Mermaid図](mermaid.md)を参照する。

ローカル画像の相対パスは、表示中のMarkdownファイルを基準に解決する。絶対パス、`file://`、空白などのURLエンコードにも対応する。
