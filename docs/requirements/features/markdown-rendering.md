# Markdown描画

[全体像に戻る](../index.md)

## 目的と位置づけ

Markdownの本文、表、コード、画像などを、整形された状態で閲覧できるようにします。

## 要件

次の要素を表示する。

- 見出し、段落、箇条書き、引用、リンク。
- 表、チェックリスト。チェックリストは閲覧対象であり、ファイルを書き換えない。
- コードブロックとシンタックスハイライト。
- ローカル画像とWeb上の画像。
- Mermaid図。詳細は[Mermaid図](mermaid.md)を参照する。

ローカル画像の相対パスは、表示中のMarkdownファイルを基準に解決する。絶対パス、`file://`、空白などのURLエンコードにも対応する。

### 本文幅と要素の配置

- [画面と操作モード](viewer-ui.md#本文領域の配置)で定める本文領域の幅の中に、各要素を配置する。
- 表とコードブロックは、本文幅に収まらない場合、その要素内で横スクロールできるようにする。通常の本文の幅を押し広げない。
- 画像とMermaid図は、縦横比を維持して本文幅に収める。
- 本文領域の配置によって文字自体を中央揃えにはしない。表のセルなど、Markdownによる明示的な配置指定は維持する。

### 配色

本文・見出し・リンク・引用・コード背景の配色は[表示・配色設定](display-settings.md)に従う。コードのシンタックスハイライトは標準カラースキームに合わせるが、画像の色とMermaid図内の配色は変更しない。

## 受け入れ条件

- [ ] 幅の広い表・コードブロックを要素内で横スクロールでき、通常の本文領域を押し広げない。
- [ ] 画像・Mermaid図は、縦横比を維持して本文幅に収まる。
- [ ] 本文領域の配置を変更しても、表のセルなどのMarkdownによる明示的な配置指定を維持する。
