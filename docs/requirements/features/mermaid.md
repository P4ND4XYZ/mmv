# Mermaid図

[全体像に戻る](../index.md)

## 目的と位置づけ

Markdown内のMermaid図を、本文の表示を妨げずに閲覧できるようにします。

## 要件

### 対応範囲と表示

- フローチャート、クラス図、ER図を優先して検証する。
- その他の図も使う可能性があるため、この3種類だけに対応範囲を固定したわけではない。
- 図の内容を正しく読めることを前提に、公式Mermaidと多少レイアウトが異なることは許容する。
- 本文を先に表示し、未生成の図をバックグラウンドで生成して、生成でき次第表示する。
- 図の表示によってレイアウトが変化する場合も、読んでいた箇所を保つ。
- Node.jsやmermaid-cliなどの事前インストールを利用者へ求めることは許容する。

### キャッシュ

- 生成済みの図をキャッシュし、描画結果に影響する条件が同じなら再利用する。
- 本文だけが変わり、図に関する条件が変わっていない場合は再生成しない。
- 図の内容が変更された場合は、その図を再生成する。
- キャッシュはアプリ終了後も保持し、再起動後も再利用できるようにする。
- 有効なキャッシュがあれば、mermaid-cliがなくても表示する。

### 生成できない場合

| 状況 | 動作 |
|---|---|
| キャッシュがなく、mermaid-cliもない | 対象の図を非表示にし、エラーログを残す |
| 構文エラーなどで生成に失敗 | 対象の図を非表示にし、エラーログを残す |
| 図の変更後に再生成が失敗 | 内容の異なる古い図は表示しない |

- 本文や他の画像の表示は継続する。
- 失敗した図のソースコードやエラーメッセージを、ビューアー上には表示しない。
- ログには対象ファイル、図の位置、失敗理由を残す。
- 同じエラーが繰り返し大量に記録されないようにする。
