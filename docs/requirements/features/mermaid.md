# Mermaid図

[全体像に戻る](../index.md)

## 目的と位置づけ

Markdown内のMermaid図を、本文の表示を妨げずに閲覧できるようにします。

## 要件

### 対応範囲と表示

- フローチャート、クラス図、ER図を優先して検証する。
- その他の図も使う可能性があるため、この3種類だけに対応範囲を固定したわけではない。
- 図の内容を正しく読めることを前提に、公式Mermaidと多少レイアウトが異なることは許容する。
- 本文を先に表示し、未生成の図をバックグラウンドで生成して、生成でき次第表示する。
- 図の縦横比を維持して表示領域に収める。
- 図の後付け表示によってレイアウトが変化する際、読んでいた箇所を復元する処理は行わない。
- 図のラベルと非表示のMermaidソースは本文検索の対象に含めない。
- 文書や図の内容が変わった後に、古い生成結果で現在の表示を上書きしない。
- Node.jsやmermaid-cliなどの事前インストールを利用者へ求めることは許容する。

### 初期版の生成結果と一時生成物

- 永続キャッシュは初期版の対象外とし、生成した図を終了後の再利用用には保存しない。
- 再読み込み時に、内容が変わっていない図を再生成することは許容する。
- 不要になった一時生成物は削除し、異常終了で残ったものも次回起動時に整理する。

### 生成できない場合

| 状況 | 動作 |
|---|---|
| mermaid-cliがない | 対象の図を非表示にし、エラーログを残す |
| 構文エラーなどで生成に失敗 | 対象の図を非表示にし、エラーログを残す |
| 図の変更後に再生成が失敗 | 内容の異なる古い図は表示しない |

- 本文や他の画像の表示は継続する。
- 失敗した図のソースコードやエラーメッセージを、ビューアー上には表示しない。
- ログの保存先、記録内容、ローテーション、書き込み失敗時の扱いは[エラーログ](logging.md)に従う。

## 受け入れ条件

- [ ] 図の生成完了を待たずに本文を読み、検索やスクロールを行える。
- [ ] 図を生成できなくても本文を表示し続け、失敗した図のソースやエラー詳細を画面に出さずログへ記録する。

## 後続版の永続キャッシュ（初期版の対象外）

永続キャッシュは優先度を下げ、初期版には含めない。以下は後続版で実装する際の要件として保持し、初期版の受け入れ条件には含めない。

### 再利用

- 生成済みの図をキャッシュし、描画結果に影響する条件が同じなら再利用する。
- 本文だけが変わり、図に関する条件が変わっていない場合は再生成しない。
- 図の内容が変更された場合は、その図を再生成する。
- キャッシュはアプリ終了後も保持し、再起動後も再利用できるようにする。
- 有効なキャッシュがあれば、mermaid-cliがなくても表示する。
- 保存先は`%LOCALAPPDATA%\my-markdown-viewer\cache\mermaid\`とする。

### 容量管理

- 合計容量の上限は100 MiBとする。起動時と新しい図のキャッシュ保存時に確認し、上限を超える場合は最終利用日時が古い順に削除して80 MiB以下にする。
- 単体で100 MiBを超える図は表示するが、永続キャッシュには保存しない。
- キャッシュを削除しても、表示中の図は消さない。
- 容量は固定設定とし、キャッシュ用の設定画面や手動削除コマンドは設けない。

### 最終利用日時

- 文書を開いたり再読み込みしたりして、キャッシュを表示用に読み込んだ時点を利用とみなす。
- 新しい図を生成・表示してキャッシュに保存した場合も、最終利用日時を記録する。
- 図が実際に画面内へ入ったかは追跡しない。起動時の容量確認だけでは利用日時を更新しない。
- 「30日間使っていなければ削除」のような期間の閾値は設けない。古い図も容量内なら残す。
- 削除した図を再び表示するには再生成が必要となる。mermaid-cliがなければ、その図は表示できない。

利用日時の保存方式は[後続版のキャッシュ設計](../../design/index.md#後続版のmermaidキャッシュ)を参照する。
