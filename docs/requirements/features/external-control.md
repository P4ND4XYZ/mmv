# 外部操作

[全体像に戻る](../index.md)

## 目的と位置づけ

Neovimなどの外部アプリにフォーカスを残したまま、ビューアーの表示を操作できるようにします。

## CLIの構文

実行名は`mmv`（Windowsでは`mmv.exe`）とし、ファイルを開く操作と外部操作の共通の入口にする。

| コマンド | 操作 |
|---|---|
| `mmv open FILE` | 指定したMarkdownファイルを開く |
| `mmv FILE` | `mmv open FILE`の省略形 |
| `mmv scroll down` / `mmv scroll up` | 下／上へ本文1行程度スクロール |
| `mmv scroll half-down` / `mmv scroll half-up` | 下／上へ半ページ移動 |
| `mmv scroll page-down` / `mmv scroll page-up` | 下／上へ1ページ移動 |
| `mmv top` / `mmv bottom` | ファイル先頭／末尾へ移動 |
| `mmv back` / `mmv forward` | 履歴の戻る／進む |

スクロール距離は[キーボードによる移動](navigation.md)と同じ意味で扱う。`FILE`は1つのファイルパスとし、ファイル名がサブコマンド名と同じ場合は`mmv open FILE`で明示する。

## 起動状態とフォーカス

外部操作によって、外部アプリからビューアーへフォーカスを移さない。

| 状況 | 動作 |
|---|---|
| 未起動時にファイルを開く | ビューアーを起動し、指定ファイルを表示 |
| 起動済みのときにファイルを開く | 既存のウィンドウで指定ファイルへ切り替え |
| 未起動時にスクロールや履歴移動を実行 | ビューアーを起動せず、CLIが失敗を返す |
| 起動済みビューアーへ接続できない | CLIが接続失敗を終了コードで呼び出し元へ伝える |

接続失敗を、必ず未起動が原因であると扱わない。

## 入力モードとの関係

- 外部CLI操作はNormal・Search・Commandのいずれでも受け付ける。キーボードのNormal専用操作とは区別する。
- ファイルを開く、スクロール、先頭・末尾への移動、履歴移動のいずれでも、現在の入力モードと入力中の文字列を維持する。入力の確定や取消は行わない。
- Search中に文書が置き換わった場合は、編集中の検索語で新しい本文の一致を更新する。検索結果の更新だけを理由にスクロールしない。CLI操作で指定したスクロールや履歴の位置復元は実行する。
- 読み込み中やエラーの通知で入力中の文字列を置き換えず、画面の通知はNormalの入力行で表示する。CLIへの失敗応答は入力モードにかかわらず返す。

## ファイル指定と履歴

- 相対パスは、CLIを実行した側のカレントディレクトリを基準に解釈する。起動済みビューアーのカレントディレクトリや、表示中のMarkdownファイルの場所を基準にしない。
- 空白を含むパスは引用符で指定する。たとえば`mmv open "notes/日本語 memo.md"`とする。
- CLIで別ファイルを開いた場合も[履歴](links-history.md#履歴)へ記録する。
- 現在表示中と同じファイルを指定した場合は再読み込みとし、履歴を増やさない。再読み込み時のスクロール距離と検索語の扱いは[ファイル表示と更新](file-viewing.md)に従う。

## 成功・失敗と待機

- ファイルを開く操作では、要求を送っただけでは成功とせず、ファイル読み込みの成否まで待つ。
- 未起動時にファイルを開く場合も、ビューアーの起動後、ファイル読み込みの成否をCLIへ返す。
- 存在しないファイルや読み込みエラーは、CLIにも失敗として返す。
- Mermaidの生成や画像のロード完了までは待たない。
- 各段階の待機には次の上限を設け、無期限に待機しない。

| 待機する処理 | 上限 |
|---|---|
| 既存ビューアーへの接続 | 5秒 |
| 未起動時のビューアー起動 | 30秒 |
| ファイル読み込み結果の応答 | 30秒 |

上限に達した場合は終了コード`1`で終了し、タイムアウトした旨を標準エラー出力へ出す。

- タイムアウトではCLIの待機だけを終了し、ビューアーを強制終了しない。
- 送信済みの操作はタイムアウト後に完了する可能性がある。タイムアウトを操作が未実行だったことの保証とはしない。
- CLIはタイムアウトした操作を自動再送しない。

## 終了コードと出力

| 終了コード | 意味 |
|---|---|
| `0` | 成功 |
| `1` | 接続失敗、ファイル読み込み失敗、タイムアウトなどの実行エラー |
| `2` | 引数不足、不正なコマンドなどの使い方のエラー |

- 操作の成功時は通常何も出力しない。
- 操作の失敗理由は標準エラー出力へ出す。
- `--help`と`--version`は標準出力へ表示し、終了コード`0`で終了する。これらの情報表示ではビューアーを起動しない。

## 受け入れ条件

- [ ] `mmv open FILE`と`mmv FILE`の両方で同じファイルを開ける。
- [ ] 起動済みのビューアーに対しても、相対パスがCLI側のカレントディレクトリを基準に解釈される。
- [ ] 別ファイルへの切り替えは履歴に記録され、同じファイルの再読み込みでは履歴が増えない。
- [ ] ファイル読み込みの失敗をCLIの終了コードと標準エラー出力で検知でき、Mermaid生成完了までは待たない。
- [ ] 未起動時のスクロール・履歴移動でビューアーを起動せず、外部操作でフォーカスを奪わない。
- [ ] 各段階の待機が上限に達した場合、終了コード`1`と標準エラー出力でタイムアウトを通知する。
- [ ] Search・Command中にも外部CLI操作を実行でき、入力モードと入力中の文字列が失われない。
