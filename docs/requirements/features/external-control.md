# 外部操作

[全体像に戻る](../index.md)

## 目的と位置づけ

外部アプリにフォーカスを残したまま、ビューアーの表示を操作できるようにします。

## CLIの構文

実行名は`mmv`（Windowsでは`mmv.exe`）とし、ファイルを開く操作と外部操作の共通の入口にする。

| コマンド | 操作 |
|---|---|
| `mmv open FILE` | 指定したMarkdownまたはPDFファイルを開く。表示中と同じファイルなら再読み込みしない |
| `mmv open FILE --line N` | 必要ならファイルを開き、保存済みソースの指定行に対応する箇所を表示する |
| `mmv FILE` | `mmv open FILE`の省略形 |
| `mmv scroll down` / `mmv scroll up` | 下／上へ本文1行程度スクロール |
| `mmv scroll half-down` / `mmv scroll half-up` | 下／上へ半ページ移動 |
| `mmv scroll page-down` / `mmv scroll page-up` | 下／上へ1ページ移動 |
| `mmv top` / `mmv bottom` | ファイル先頭／末尾へ移動 |
| `mmv back` / `mmv forward` | 履歴の戻る／進む |

## 起動状態とフォーカス

外部操作によって、外部アプリからビューアーへフォーカスを移さない。

| 状況 | 動作 |
|---|---|
| 未起動時にファイルを開く | ビューアーを起動し、指定ファイルを表示 |
| 起動済みのときにファイルを開く | 既存のウィンドウで指定ファイルへ切り替え |
| 未起動時にスクロールや履歴移動を実行 | ビューアーを起動せず、CLIが失敗を返す |
| 起動済みビューアーへ接続できない | CLIが接続失敗を終了コードで呼び出し元へ伝える |

## 入力モードとの関係

外部操作はNormal・Search・Commandのいずれでも受け付ける。

## ファイル指定

相対パスは、CLIを実行した側のカレントディレクトリを基準に解釈する。

## 履歴

- 外部操作で別ファイルを開いた場合に[履歴](links-history.md#履歴)へ記録する。
- 現在表示中と同じファイルを指定した場合は再読み込みせず、履歴を増やさない。
- 同じファイル内の行移動は履歴を増やさない。

## 行指定

- ソース行指定はMarkdown専用とする。
- `mmv open FILE --line N`の`N`は1始まりのソース行番号とする。正のu64の範囲で受け付け、0・負数・整数でない値・範囲超過・値欠落・重複指定は終了コード`2`の引数エラーとする。

## 成功・失敗と待機

- ファイルを開く操作は、必要なファイル読み込みの成否を確認する。
- 存在しないファイルや読み込みエラーは、CLIにも失敗として返す。
- Mermaidの生成や画像のロード完了までは待たない。

| 待機する処理 | 上限 |
|---|---|
| 既存ビューアーへの接続 | 5秒 |
| 未起動時のビューアー起動 | 30秒 |
| ファイル読み込み結果の応答 | 30秒 |

上限に達した場合は終了コード`1`で終了し、タイムアウトした旨を標準エラー出力へ出す。

## 終了コードと出力

| 終了コード | 意味 |
|---|---|
| `0` | 成功 |
| `1` | 接続失敗、ファイル読み込み失敗、タイムアウトなどの実行エラー |
| `2` | 引数不足、不正なコマンドなどの使い方のエラー |

- 操作の成功時は通常何も出力しない。
- 操作の失敗理由は標準エラー出力へ出す。
