# 外部操作

[全体像に戻る](../index.md)

## 目的と位置づけ

外部アプリにフォーカスを残したまま、ビューアーの表示を操作できるようにします。

## CLIの構文

実行名は`mmv`（Windowsでは`mmv.exe`）とし、ファイルを開く操作と外部操作の共通の入口にする。

| コマンド | 操作 |
|---|---|
| `mmv open FILE` | 指定したMarkdownファイルを開く。表示中と同じファイルなら再読み込みしない |
| `mmv open FILE --line N` | 必要ならファイルを開き、保存済みソースの指定行に対応する箇所を表示する |
| `mmv FILE` | `mmv open FILE`の省略形 |
| `mmv scroll down` / `mmv scroll up` | 下／上へ本文1行程度スクロール |
| `mmv scroll half-down` / `mmv scroll half-up` | 下／上へ半ページ移動 |
| `mmv scroll page-down` / `mmv scroll page-up` | 下／上へ1ページ移動 |
| `mmv top` / `mmv bottom` | ファイル先頭／末尾へ移動 |
| `mmv back` / `mmv forward` | 履歴の戻る／進む |

スクロール距離は[キーボードによる移動](navigation.md)と同じ意味で扱う。`FILE`は1つのファイルパスとし、ファイル名がサブコマンド名と同じ場合は`mmv open FILE`で明示する。

## 起動状態とフォーカス

外部操作によって、外部アプリからビューアーへフォーカスを移さない。

| 状況 | 動作 |
|---|---|
| 未起動時にファイルを開く | ビューアーを起動し、指定ファイルを表示 |
| 起動済みのときにファイルを開く | 既存のウィンドウで指定ファイルへ切り替え |
| 未起動時にスクロールや履歴移動を実行 | ビューアーを起動せず、CLIが失敗を返す |
| 起動済みビューアーへ接続できない | CLIが接続失敗を終了コードで呼び出し元へ伝える |

接続失敗を、必ず未起動が原因であると扱わない。

## 入力モードとの関係

- 外部CLI操作はNormal・Search・Commandのいずれでも受け付ける。キーボードのNormal専用操作とは区別する。
- ファイルを開く、スクロール、先頭・末尾への移動、履歴移動のいずれでも、現在の入力モードと入力中の文字列を維持する。入力の確定や取消は行わない。
- Search中に文書が置き換わった場合は、編集中の検索語で新しい本文の一致を更新する。検索結果の更新だけを理由にスクロールしない。CLI操作で指定したスクロールや履歴の位置復元は実行する。
- 読み込み中やエラーの通知で入力中の文字列を置き換えず、画面の通知はNormalの入力行で表示する。CLIへの失敗応答は入力モードにかかわらず返す。
- リンク選択パネルの表示中も外部CLI操作を受け付ける。本文が置き換わった場合だけパネルを閉じて通知し、古い候補を無効にする。Search・Commandの入力維持とは区別する。読み込み要求の受信だけや読み込み失敗、スクロール・先頭／末尾への移動だけではパネルを閉じない。パネルを閉じても外部アプリのフォーカスを奪わない。詳細は[リンク選択の仕様](links-history.md#取消文書更新失敗)に従う。

## ファイル指定と履歴

- 相対パスは、CLIを実行した側のカレントディレクトリを基準に解釈する。起動済みビューアーのカレントディレクトリや、表示中のMarkdownファイルの場所を基準にしない。
- 空白を含むパスは引用符で指定する。たとえば`mmv open "notes/日本語 memo.md"`とする。
- CLIで別ファイルを開いた場合も[履歴](links-history.md#履歴)へ記録する。
- 現在表示中と同じファイルを指定した場合は再読み込みせず、履歴を増やさない。行指定がなければ本文・表示位置・検索・監視を維持する。相対／絶対パスなどの表記差だけで別ファイルとしない。
- 保存による自動更新とF5による再読み込みは[ファイル表示と更新](file-viewing.md)に従う。CLIの`open`を再読み込みの代わりには使わない。

## ソース行の指定

- `mmv open FILE --line N`の`N`は1始まりのソース行番号とする。正のu64の範囲で受け付け、0・負数・整数でない値・範囲超過・値欠落・重複指定は終了コード`2`の引数エラーとする。省略形`mmv FILE`への`--line`追加は行わない。
- 指定行に対応する実表示行を全表示するための最小垂直移動だけを行い、すでに全表示されていれば移動しない。途中のblock先頭への移動やpaddingは加えない。
- 計測は初回込み8試行または開始から1秒の早い方で終了し、可視成功・失敗・取消しを内部で区別する。計測不能な画像・Mermaid・HTML等は明示失敗とし、blockへの代替移動はしない。新しいGUI通知や自動再試行は設けない。CLIの成功は操作の受理であり、可視化成功とは別である。
- codeの空行は実表示行、空codeは実block領域を対象とし、fenceは最初／最後のbody行へ対応付ける。block間空行等は最も近い実body行を選び、同距離なら後の行を選ぶ。最終行超過は既存の末尾方針に従う。
- 対象はscrollableかつ行数制限なしのMarkdown構成とする。非scrollable／行数制限付きは`UnsupportedGeometry`で失敗する。
- 同じファイルなら本文を読み直さず位置だけを指定する。別ファイルまたは未起動なら読み込み成功後に適用する。
- 同じファイル内の行移動は履歴を増やさない。入力モード・入力文字列・外部アプリのフォーカスを保持し、本文を置換しない行移動ではリンク選択パネルも維持する。
- 行指定は一度限りの位置移動とする。読み込み・解析・レイアウト待ちの間は未適用の指定を保持し、同じ文書の再読み込みをまたいでも適用を待つ。適用完了後は指定を破棄し、手動スクロール、再読み込み、リサイズ、画像・Mermaidの寸法変更で復活させない。再読み込みは置換直前のスクロール距離を復元し、リサイズは既存の距離保持方針に従う。
- 同じファイル・同じ行番号でも、明示的なopenは新しい位置要求として受け付ける。行指定なしの同一openは未適用の要求を変更せず、別ファイルへの切り替え成功では以前の要求を破棄する。切り替え失敗では以前の本文と未適用の要求を保持する。
- 保存済みMarkdownだけを対象とし、未保存本文の受信や双方向同期は行わない。未保存中の位置指定も受け付けるが、保存済み本文との行番号のずれは許容する。

## 成功・失敗と待機

- ファイルを開く操作では、要求を送っただけでは成功とせず、必要なファイル読み込みの成否まで待つ。同一ファイルを読み直さない場合は、同一性の確認と操作の受理結果を返す。
- 未起動時にファイルを開く場合も、ビューアーの起動後、ファイル読み込みの成否をCLIへ返す。
- 存在しないファイルや読み込みエラーは、CLIにも失敗として返す。
- Mermaidの生成や画像のロード完了までは待たない。
- 各段階の待機には次の上限を設け、無期限に待機しない。

| 待機する処理 | 上限 |
|---|---|
| 既存ビューアーへの接続 | 5秒 |
| 未起動時のビューアー起動 | 30秒 |
| ファイル読み込み結果の応答 | 30秒 |

上限に達した場合は終了コード`1`で終了し、タイムアウトした旨を標準エラー出力へ出す。

- タイムアウトではCLIの待機だけを終了し、ビューアーを強制終了しない。
- 送信済みの操作はタイムアウト後に完了する可能性がある。タイムアウトを操作が未実行だったことの保証とはしない。
- CLIはタイムアウトした操作を自動再送しない。

## 終了コードと出力

| 終了コード | 意味 |
|---|---|
| `0` | 成功 |
| `1` | 接続失敗、ファイル読み込み失敗、タイムアウトなどの実行エラー |
| `2` | 引数不足、不正なコマンドなどの使い方のエラー |

- 操作の成功時は通常何も出力しない。
- 操作の失敗理由は標準エラー出力へ出す。
- `--help`と`--version`は標準出力へ表示し、終了コード`0`で終了する。これらの情報表示ではビューアーを起動しない。

## 受け入れ条件

- [ ] `mmv open FILE`と`mmv FILE`の両方で同じファイルを開ける。
- [ ] 起動済みのビューアーに対しても、相対パスがCLI側のカレントディレクトリを基準に解釈される。
- [ ] 別ファイルへの切り替えは履歴に記録され、同じファイルへのopenでは再読み込みせず履歴も増えない。
- [ ] 通常の描画では行指定で対応箇所が表示され、すでに見えている場合はスクロールしない。空行・末尾超過・不正な行番号を規定どおり扱う。失敗・取消しも待機を解放し、queued移動の実layout正規化後の距離を後続の履歴・読み込み・リンクへ渡す。
- [ ] 未適用の行指定は保存・解析・レイアウトをまたいで保持し、古い要求で新しい位置要求を完了させない。完了後の手動スクロールを妨げず、再読み込み・リサイズ・画像更新で行指定が復活しない。同じ行の新しい要求は適用する。
- [ ] ファイル読み込みの失敗をCLIの終了コードと標準エラー出力で検知でき、Mermaid生成完了までは待たない。
- [ ] 未起動時のスクロール・履歴移動でビューアーを起動せず、外部操作でフォーカスを奪わない。
- [ ] 各段階の待機が上限に達した場合、終了コード`1`と標準エラー出力でタイムアウトを通知する。
- [ ] Search・Command中にも外部CLI操作を実行でき、入力モードと入力中の文字列が失われない。
- [ ] リンク選択パネル中の外部操作では、本文置換時はパネルを閉じて通知し、読み込み失敗やスクロールのみでは入力・パネルを維持する。いずれも外部アプリのフォーカスを奪わない。
