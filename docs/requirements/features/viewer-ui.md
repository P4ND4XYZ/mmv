# 画面と操作モード

[全体像に戻る](../index.md)

## 目的と位置づけ

本文の閲覧、検索、コマンド入力を分け、キーボード中心で操作できるようにします。

## 画面構成

- 左ツリー・右本文の固定2領域のpaneとし、ツリーは表示／非表示を切り替えられる。任意分割・複数本文・汎用paneプラグインは対象外とする。
- 本文の上部にはファイル情報のヘッダーや常設の検索欄を置かない。検索件数・前後移動ボタンも常設しない。
- 本文の下部は、横線で区切った固定の2行とする。
  - 状態行：固定幅のモード欄と、現在のファイル名を表示する。長いファイル名は省略する。
  - 入力行：Searchでは`/検索語`、Commandでは`:コマンド`を表示する。Normalでは通常空欄とし、読み込み中・エラー・通知がある場合に表示する。
- モード欄は等幅フォントで表示する。
- モード変更や長い入力でも、2行の高さとモード欄の幅、ファイル名の表示開始位置を変えない。
- Mermaidの生成エラーは入力行には表示せず、[エラーログ](logging.md)へ記録する。

次のモード色は標準カラースキームの基本とする。利用者は[表示・配色設定](display-settings.md)で上書きできる。

| モード表記 | モード欄の背景色 | 文字色 |
|---|---|---|
| NORMAL | 青 | 白 |
| SEARCH | 黄 | 濃いグレー |
| COMMAND | 紫 | 白 |

### 本文領域の配置

- 本文領域の幅と配置を本文pane内の利用可能幅を基準に計算する方針は、[paneの詳細設計](../../design/components/file-tree.md#pane配置フォーカスの案)で扱う設計案であり、確定要件ではない。ツリーは通常240論理pxとし、ドラッグリサイズ・幅保存は行わない。本文paneの最小幅は240論理pxとし、ウィンドウ最小幅で本文240＋ツリー240＋境界線などの必要幅を確保する。この最小幅は本文paneの領域確保を指し、`view.max_width`による本文内容の最大幅とは区別する。
- 本文領域は標準で横方向に中央配置し、通常の本文の文字は左詰めとする。短い文書でも縦方向には中央配置せず、上詰めとする。
- 配置は`view.position`、最大幅は`view.max_width`で指定する。設定値と初期値は[表示・配色設定](display-settings.md)を参照する。
- 広いウィンドウでは最大幅を超えて本文領域を広げない。中央配置では左右に余白を置き、左側配置では左側に寄せる。
- 狭いウィンドウでは、左右の最小余白を除いた利用可能な幅まで本文領域を縮める。
- 下部の状態行・入力行は本文の最大幅や配置にかかわらずウィンドウ全幅とする。
- 表・コード・画像・Mermaid図の幅と、Markdownによる配置指定は[Markdown描画](markdown-rendering.md#本文幅と要素の配置)に従う。

## 表示言語と通知

アプリが生成するGUIのエラー・警告・案内・状態・空表示・種類ラベル・アクセシビリティ文言は英語に統一する。Markdown本文、ファイル名・パス、URL、見出しID、利用者の入力は翻訳しない。モード欄のNORMAL／SEARCH／COMMANDは維持する。ローカライズ基盤は追加せず、ログとCLI全体の翻訳は対象外とする。

OSや描画基盤の生エラーは画面へ流さず、固定英語へ分類し、対象パスと詳細原因を既存ログへ記録する。通知に付けるパス・ID・入力は元の文字列を維持する。以下の入力行表示はNormalで表示し、Search／Commandでは入力モードと文字列を保護する。ダイアログは使わない。

| 条件 | 英語表示 | 位置 | 保持する状態 |
|---|---|---|---|
| 文書要求が処理中 | `Loading…` | 入力行 | 既存本文・距離・履歴 |
| ファイル不在 | `File not found: {path}` | 入力行 | 本文・距離・履歴・ツリー |
| アクセス拒否・ロック | `File access denied or locked: {path}` | 入力行 | 同上 |
| 不正UTF-8 | `File is not valid UTF-8: {path}` | 入力行 | 同上 |
| ツリー対象・祖先が通常非reparseでない、ルート外など | `Tree target is not a regular accessible file: {path}` | 入力行 | 同上 |
| ドライブ切断・一般I/O・未知のOS原因 | `Unable to read file: {path}` | 入力行 | 同上 |
| 設定の読み込み・実行・検証失敗 | `Unable to load configuration` | 入力行 | 標準設定で本文閲覧を継続 |
| 検索一致なし | `No matches found` | 入力行 | 本文・履歴、Normalへ戻る |
| 再利用する検索語なし | `No previous search query` | 入力行 | 本文・履歴、Normalへ戻る |
| 未対応コマンド | `Unsupported command: :{input}` | 入力行 | 本文・履歴、Normalへ戻る |
| 文書の読み込み／解析待ち | `Document is loading` / `Document is being analyzed` | 入力行 | 本文・履歴 |
| 位置解析・リンク解析・検索強調の失敗 | `Unable to determine document positions` / `Unable to analyze document links` / `Unable to highlight search results` | 入力行 | 本文・履歴 |
| 見出しがない | `Heading not found: {id}` | 入力行 | 採用した本文を先頭表示 |
| 本文置換でリンク選択を終了 | `Link selection closed because the document changed` | 入力行 | 新しい本文・入力モードと文字列 |
| リンク候補なし | `No matching links` | 選択パネル | パネル入力・本文・履歴 |
| フォルダー一覧取得失敗 | `Unable to access directory.` | ツリー内 | 既存一覧・本文・入力。ルート不能時だけカーソルをルートへ |
| リンクの種類 | `Heading` / `Markdown` / `Markdown heading` / `Web` | 選択パネル | 本文由来の表示名と宛先 |
| Mermaidのアクセシビリティ | `Mermaid diagram` | 図のアクセシビリティラベル | 図の内容は翻訳しない |

リンク形式の不正時は既存の英語要約（`invalid URL`、`invalid file URL`、`invalid fragment encoding`、`invalid UTF-8 fragment`、`document path must be absolute`、`unsupported link scheme: {scheme}`）を入力行へ表示し、本文・履歴を保持する。Mermaid生成失敗は引き続き画面には出さずログだけとする。

## モードと入力

- 起動時はNormalモードとする。
- 本文にフォーカスがあるNormalでは、[本文スクロール](navigation.md)、検索結果の次／前への移動、`F5`による再読み込み、`f`による[リンク選択パネル](links-history.md#キーボードによるリンク選択)の表示を受け付ける。
- 本文にフォーカスがあるNormalの`/`で、空入力のSearchモードへ移る。検索の振る舞いは[本文検索](search.md)を参照する。
- 本文にフォーカスがあるNormalの`:`で、空入力のCommandモードへ移る。
- Search・Commandの入力中は、キーボードのNormal専用操作を実行しない。たとえば`j`、`n`、`N`は入力文字として扱う。
- 外部CLI操作は入力中も受け付け、入力モードと入力中の文字列を維持する。詳細は[外部操作](external-control.md#入力モードとの関係)を参照する。
- IMEの未確定文字が残るEnterでは、検索確定やコマンド実行を行わず、入力モードを維持する。変換確定後のEnterで実行する。

## ファイルツリーとの行き来

`Ctrl+Shift+e`でツリー表示を切り替える。表示中は`Ctrl+W`に続けて`h`で左のツリーへ、`l`で右の本文へフォーカスを移す。移動先がない場合は何もしない。初期フォーカスは本文とする。

ツリー入力と本文入力は分離し、ツリーでは本文検索・履歴移動・本文再読み込み・F5を受け付けない。Search・Command・リンク選択パネル・IME変換中はpane移動と表示切替を受け付けない。表示対象・カーソル・状態保持・ルート追従・エラー時の振る舞いは[ファイルツリー](file-tree.md)にまとめる。一覧取得エラーはツリー内に表示し、本文や入力欄を置き換えない。ツリーから文書を開く失敗は入力行に英語で表示する。Enter／`l`で別文書を正常に開いたら本文へフォーカスを移す。同じファイルなら再読み込みせず本文へフォーカスだけを移す。失敗時は現在の文書とツリーフォーカスを保持する。`→`では文書を開かない。

2打目待機中の取消・タイムアウト・無効キー・修飾キーはGPUI標準のキー割り当て機構に従い、独自規則は設けない。共通選択パネルの取消操作を、そのままツリーの操作として追加しない。

## 共通の選択パネル

リンク選択には、左の候補一覧・右のリンク記述周辺のソースプレビュー・下部の検索入力欄を持つ一時的なフローティングパネルを使う。本文上に重ねて表示し、常設の検索欄や下部2行の置き換えにはしない。

- リンク選択パネルは本文にフォーカスがあるNormalモードからだけ開く。Search・Commandの入力中は開かない。
- パネル表示中は検索欄へフォーカスを移し、キーボードのNormal専用操作を実行しない。`j`・`k`・`n`などはパネルの入力文字として扱い、`f`で別のパネルを重ねて開かない。
- 再描画だけでは入力・選択を初期化せず、フォーカスを移し直さない。
- 確定または取消で閉じた後は本文へフォーカスを戻し、Normalのキー操作を再開する。ただし、外部CLI操作や自動更新に伴う終了では、外部アプリからビューアーへフォーカスを奪わない。
- パネルの検索入力は本文検索・コマンド入力と分ける。プレビューの表示範囲と初期案、リンク固有の候補・順序・文書更新時の扱いは[リンク選択の仕様](links-history.md#キーボードによるリンク選択)に従う。

| 操作 | 動作 |
|---|---|
| 文字入力 | 候補を絞り込む |
| `↓` / `↑`、`Ctrl+n` / `Ctrl+p` | 次／前の候補を選択する |
| Enter | 選択中の候補を確定する。候補がなければ何もしない |
| Esc | 検索入力の有無にかかわらず、実行せず1回でパネルを閉じる |
| パネル外クリック | 実行せずパネルを閉じる。同じクリックで背後の本文リンクなどを操作しない |

IME変換中は変換操作を優先する。変換確定のEnterでは候補を実行せず、変換確定後の別のEnterで実行する。変換中のEscでは変換取消を優先し、パネルを閉じない。

パネルの入力・候補表示・選択・確定・取消・フォーカス制御は、リンク以外にも再利用できる共通の選択UIとして扱う。リンク候補の取得やリンクを開く動作は、この共通部分とは分離する。

## コマンド入力

| 操作 | 動作 |
|---|---|
| `q`を入力してEnter（`:q`） | ウィンドウを閉じる |
| `noh`または`nohlsearch`を入力してEnter | [検索ハイライトを解除](search.md#ハイライトの解除と再表示)し、Normalへ戻る |
| 未対応のコマンドをEnter | 未対応の旨を表示し、Normalへ戻る |
| Esc | 実行せずNormalへ戻る |
| 空入力でBackspace | Normalへ戻る |
| 文字がある状態でBackspace | 文字の削除だけを行う。最後の1文字を削除した時点ではCommandを維持する |

アプリ内コマンドは`:q`、`:nohlsearch`とその別名の`:noh`を対象とする。任意のコマンド省略を解釈する仕組みは設けない。任意のファイルパスを指定して開く入口はCLIとし、`:e`などは追加しない。文書内のリンクを開く操作には、クリックとリンク選択パネルを使う。

## 受け入れ条件

- [ ] 起動時はNormalとなり、モード変更や長いファイル名・入力で下部2行の寸法が変わらない。
- [ ] 本文領域を中央／左側に配置でき、文字は左詰め、文書全体は上詰めを維持する。
- [ ] 広いウィンドウでは本文の最大幅を維持し、狭いウィンドウでは幅を縮める。下部2行はウィンドウ全幅のままとなる。
- [ ] Search・Command中にキーボードのNormal専用操作が実行されず、IME未確定中のEnterで入力モードを終了しない。
- [ ] 外部CLI操作でもSearch・Commandと入力中の文字列が維持される。
- [ ] `:q`の確定で終了し、取消や未対応コマンドでは終了しない。
- [ ] Normalの`f`でパネルへ入力フォーカスが移り、Search・Command中には開かない。パネル表示中の文字入力で本文のNormal専用操作が実行されない。
- [ ] 候補を矢印または`Ctrl+n` / `Ctrl+p`で選択でき、再描画でも入力・選択・フォーカスを維持する。
- [ ] 入力があってもEscを1回押せば取消できる。パネル外クリックでも取り消せるが、そのクリックで本文リンクは開かない。
- [ ] IME変換確定のEnterでは候補を実行せず、変換取消のEscではパネルを閉じない。変換終了後のEnter・Escでは確定・取消できる。
- [ ] パネル終了後は本文のキー操作へ戻り、外部CLIによる本文置換で終了しても外部アプリのフォーカスを奪わない。
