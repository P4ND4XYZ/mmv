# 画面と操作モード

[全体像に戻る](../index.md)

## 目的と位置づけ

本文の閲覧、検索、コマンド入力を分け、キーボード中心で操作できるようにします。

## 画面構成

- 本文の上部にはファイル情報のヘッダーや常設の検索欄を置かない。検索件数・前後移動ボタンも常設しない。
- 本文の下部は、横線で区切った固定の2行とする。
  - 状態行：固定幅のモード欄と、現在のファイル名を表示する。長いファイル名は省略する。
  - 入力行：Searchでは`/検索語`、Commandでは`:コマンド`を表示する。Normalでは通常空欄とし、読み込み中・エラー・通知がある場合に表示する。
- モード欄は等幅フォントで表示する。
- モード変更や長い入力でも、2行の高さとモード欄の幅、ファイル名の表示開始位置を変えない。
- Mermaidの生成エラーは入力行には表示せず、[エラーログ](logging.md)へ記録する。

| モード表記 | モード欄の背景色 | 文字色 |
|---|---|---|
| NORMAL | 青 | 白 |
| SEARCH | 黄 | 濃いグレー |
| COMMAND | 紫 | 白 |

## モードと入力

- 起動時はNormalモードとする。
- Normalでは、[本文スクロール](navigation.md)、検索結果の次／前への移動、`F5`による再読み込みを受け付ける。
- Normalの`/`で、空入力のSearchモードへ移る。検索の振る舞いは[本文検索](search.md)を参照する。
- Normalの`:`で、空入力のCommandモードへ移る。
- Search・Commandの入力中は、キーボードのNormal専用操作を実行しない。たとえば`j`、`n`、`N`は入力文字として扱う。
- 外部CLI操作は入力中も受け付け、入力モードと入力中の文字列を維持する。詳細は[外部操作](external-control.md#入力モードとの関係)を参照する。
- IMEの未確定文字が残るEnterでは、検索確定やコマンド実行を行わず、入力モードを維持する。変換確定後のEnterで実行する。

## コマンド入力

| 操作 | 動作 |
|---|---|
| `q`を入力してEnter（`:q`） | ウィンドウを閉じる |
| 未対応のコマンドをEnter | 未対応の旨を表示し、Normalへ戻る |
| Esc | 実行せずNormalへ戻る |
| 空入力でBackspace | Normalへ戻る |
| 文字がある状態でBackspace | 文字の削除だけを行う。最後の1文字を削除した時点ではCommandを維持する |

アプリ内コマンドは`:q`のみを対象とする。ファイルを開く共通の入口はCLIとし、`:e`などは追加しない。

## 受け入れ条件

- [ ] 起動時はNormalとなり、モード変更や長いファイル名・入力で下部2行の寸法が変わらない。
- [ ] Search・Command中にキーボードのNormal専用操作が実行されず、IME未確定中のEnterで入力モードを終了しない。
- [ ] 外部CLI操作でもSearch・Commandと入力中の文字列が維持される。
- [ ] `:q`の確定で終了し、取消や未対応コマンドでは終了しない。
