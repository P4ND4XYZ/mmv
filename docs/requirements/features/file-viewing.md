# ファイル表示と更新

[全体像に戻る](../index.md)

## 目的と位置づけ

文書を開いて閲覧し、外部エディターで保存した変更を確認できるようにします。

## 要件

### ファイルを開く

- `mmv open FILE`または省略形の`mmv FILE`で指定されたMarkdownまたはPDFファイルを開く。
- MarkdownはUTF-8とBOM付きUTF-8を読み込む。他の文字コードは読み込みエラーとする。
- ファイルをバックグラウンドで読み込む。
- 読み込みに失敗した場合は、[Normalモードの入力行](viewer-ui.md)にエラーを表示する。

### 自動更新

- 表示中のファイルが保存されたら、表示を自動更新する。
- 自動更新の成功時は、更新前の上端からのスクロール距離を維持する。文書が短くなった場合は、スクロール可能な末尾までに収める。
- 再読み込みに失敗した場合は、直前の文書を保持してエラーを表示する。
- 自動更新による動作モードの遷移を行わない。

## 受け入れ条件

- 再読み込み後はスクロール距離を維持し、文書が短くなった場合もスクロール可能な範囲に収まる。
