# ファイル表示と更新

[全体像に戻る](../index.md)

## 目的と位置づけ

文書を開いて閲覧し、外部エディターで保存した変更を確認できるようにします。

## 要件

### ファイルを開く

- `mmv open FILE`または省略形の`mmv FILE`で指定されたMarkdownファイルを開く。パスの解釈、同じファイルの指定、終了コードは[外部操作のCLI仕様](external-control.md)に従う。
- 表示中の文書に含まれるローカルMarkdownへのリンクは、クリックまたはキーボードのリンク選択パネルから開ける。詳細は[リンクと履歴](links-history.md)に従う。
- UTF-8とBOM付きUTF-8を読み込む。他の文字コードは読み込みエラーとする。
- ファイルをバックグラウンドで読み込み、UIを待たせない。
- 複数の読み込み要求が前後して完了しても、古い要求の結果で現在の表示を上書きしない。
- 読み込みに失敗した場合は、[Normalモードの入力行](viewer-ui.md)にエラーを表示する。Search・Command中は入力を維持し、エラーのためにNormalへ切り替えない。すでに表示中の文書があれば、その文書を保持する。
- 外部CLIによるファイル切り替え・再読み込みでも、入力モードと入力中の文字列を維持する。詳細は[外部操作](external-control.md#入力モードとの関係)を参照する。

### 自動更新と手動再読み込み

- 表示中のファイルが保存されたら、表示を自動更新する。
- 本文にフォーカスがあるNormalモードの`F5`で、現在表示中のファイルを手動で再読み込みする。リンクで別ファイルへ切り替えた後は、そのファイルを対象とする。
- 自動更新・手動再読み込みの成功時は、更新前の上端からのスクロール距離を維持する。文書が短くなった場合は、スクロール可能な末尾までに収める。
- 前方に文章が追加・削除されても同じ段落を表示し続ける、といった内容を基準にした位置復元は行わない。
- 再読み込みに失敗した場合は、直前の文書を保持してエラーを表示する。
- Search・Commandモード中に自動更新されても、モードと入力中の文字列を維持する。
- リンク選択パネルを表示中に本文を置き換えた場合は、古い候補を使わないようパネルを閉じて通知する。読み込み失敗で本文を保持する場合は閉じない。詳細は[リンク選択の仕様](links-history.md#取消文書更新失敗)を参照する。
- 確定済み検索語は再読み込み・別ファイルへの切り替え後も引き継ぐ。Normal・Commandでは確定済み検索語、Searchでは編集中の検索語で一致を更新する。検索による自動移動は行わない。詳細は[本文検索](search.md)を参照する。

## ファイルツリーとの境界

- 文書を正常に採用したら[ファイルツリーのルート追従](file-tree.md#文書に応じたルート)を適用し、読み込み失敗ではツリーを変更しない。同一ルートなら展開・カーソル・スクロールを保持し、一覧を再取得しない。
- ツリーの表示切替・移動・展開・一覧更新で本文を再読み込みせず、文書・履歴・入力を再初期化しない。ツリーの`r`と本文の`F5`は別操作とし、ツリーではF5を受け付けない。
- ツリーは自動監視しない。現在本文のファイル監視をツリー全体へ拡張しない。

## 受け入れ条件

- [ ] 表示中のファイルの保存と`F5`の両方で、表示が更新される。
- [ ] 再読み込み後はスクロール距離を維持し、文書が短くなった場合もスクロール可能な範囲に収まる。
- [ ] Search・Command中の自動更新で、モードと入力中の文字列が失われない。
- [ ] 読み込み失敗や古い要求の完了によって、表示中の文書が失われたり古い文書へ戻ったりしない。
