# リンクと履歴

[全体像に戻る](../index.md)

## 目的と位置づけ

関連文書や見出しへのリンクをたどり、履歴を使って移動前後の閲覧位置を行き来できるようにします。

## 要件

リンクはマウスクリックに加えて、Vimiumのように各リンクへ文字ラベルを表示して選択する方法で開けるようにする。

| リンク先 | 動作 |
|---|---|
| 同じファイル内の見出し | 指定された見出しへ移動 |
| 別のローカルMarkdown | このビューアーで開き、現在の表示を置き換える |
| 別のローカルMarkdown内の見出し | ファイルを開き、指定された見出しへ移動 |
| Webページ | 既定のブラウザーで開く |

履歴の扱いは次のとおり。

- ファイル間の移動と、同じファイル内の見出しリンクによる移動を対象とする。
- 通常のスクロールは履歴に含めない。
- `Ctrl+o`で戻り、`Ctrl+i`で進む。
- 戻る／進むときは、その履歴の閲覧位置を復元する。
