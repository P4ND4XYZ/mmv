# ファイルツリー

[全体像に戻る](../index.md)

## 目的と位置づけ

閲覧中の文書が属するプロジェクトのフォルダー・ファイル構成を、本文と行き来しながら確認できるようにします。

本書は合意済みの利用者から見える振る舞いをまとめた要件です。実装済みであることを示すものではありません。まだ合意していない操作や設定は「未決定事項」に分けています。

## 要件

### 表示と対象範囲

- ファイルツリーの表示／非表示を切り替えられる。
- フォルダーの展開・折り畳みと項目の選択ができる。
- Markdownに限らず、画像、PDF、ソース、設定ファイル、拡張子のないファイルも表示する。拡張子による絞り込みは行わない。隠し属性や特定フォルダーの除外は未決定とする。
- 初期版は構造の閲覧専用とする。ファイルをクリック・ダブルクリック・Enterで選択しても、本文への表示、プレビュー、外部アプリでの起動は行わない。
- ツリーの表示切り替え・選択・展開・折り畳み・フォーカス移動だけでは、表示中の文書を別ファイルへ切り替えたり、閲覧履歴を追加したりしない。
- ツリーからのファイル作成・編集・削除・移動は行わない。

文書を開く操作は引き続き[ファイル表示と更新](file-viewing.md)に従う。ツリーからファイルを開く機能は将来対応であり、今回の要件には含めない。

### 起動時の表示状態

- ユーザー単位のLua設定で、起動時にツリーを表示するか非表示にするかを指定できる。
- 設定の読み込み先と反映時期は[表示・配色設定](display-settings.md)に従う。設定変更は再起動で反映し、文書の再読み込みや外部CLI操作では設定を再読み込みしない。文書側のLua設定は自動実行しない。
- 設定名、未指定時の表示状態、起動後に変更した表示状態の保持範囲は未決定とする。

### 本文とのフォーカス移動

ツリーと本文を表示しているとき、次の2段階のキー操作で操作先を移せる。

| キー | 動作 |
|---|---|
| `Ctrl+W`を押した後に`h` | 本文から左のツリーへフォーカスを移す |
| `Ctrl+W`を押した後に`l` | ツリーから右の本文へフォーカスを移す |

表示切り替えとフォーカス移動は別の操作として扱う。既に移動先にいる場合、ツリー非表示時、入力中、2打目の待機中の詳細な振る舞いは未決定事項を参照する。

### 文書に応じた表示範囲

- ツリーの起点となるフォルダーをルートとする。
- 別プロジェクトの文書を正常に開いたら、その文書のプロジェクトを表示するようルートを切り替える。読み込み中というだけでは切り替えない。
- 別文書の読み込みに失敗した場合は、現在の文書とツリーのルートを維持する。
- CLI、文書内リンク、履歴移動のいずれで文書を開いた場合も、この成功／失敗の扱いを適用する。
- ルートの判定規則は未決定とする。別プロジェクトへの追従方針が決まっていることと、プロジェクトの境界をどう決めるかは区別する。

### フォルダーの展開と待ち時間

- フォルダーを展開すると、その直下のフォルダー・ファイルを表示する。さらに下の階層は、該当するフォルダーを展開して確認する。
- 未展開の全階層の表示準備が終わるまで待たせない。
- 大量のファイルがあるフォルダーや共有フォルダーで一覧の表示に時間がかかっても、本文の閲覧や他の利用可能な箇所の操作を続けられる。
- 項目数の上限や一部だけを表示する場合の見せ方、追加・削除・改名の反映方法は未決定とする。

### アクセスできない場合

- フォルダーにアクセスできない場合は、その箇所を読み込めないことが分かる表示にする。空のフォルダーとしては扱わない。
- エラーの影響は該当箇所に限定し、他の利用可能な枝と表示中の本文は引き続き利用できる。
- エラーの具体的な文言、再試行の操作、ルート自体を確認できない場合の表示は未決定とする。

### シンボリックリンク・ジャンクション

- シンボリックリンクとジャンクションも項目として表示する。
- 初期版ではリンク先のフォルダーを展開しない。手動操作でもリンク先の階層は表示しない。
- ファイルへのシンボリックリンクも表示だけにとどめ、リンク先を開かない。

この制約はツリー内の操作に対するものであり、既存のCLIや文書内リンクによる文書表示の仕様を変更しない。

## 未決定事項

以下は要件として確定していない。推奨案と判断材料は[設計たたき台](../../design/components/file-tree.md)を参照する。

- 表示切替キー・クリック操作、ツリーの幅・サイズ変更・狭いウィンドウでの配置、開閉による本文の閲覧位置の扱い。
- Luaの設定名と既定値、表示状態の保持範囲、起動時のフォーカス。
- ルートの判定規則（`.marksman.toml`／`.git`の採用・優先順位、印がない場合、リンク経由で文書を開いた場合）。
- ルート変更時の展開・選択状態、現在文書の強調とその箇所までの自動展開。
- 項目移動・階層操作のキー、ツリー非表示時や既に移動先にいる場合のフォーカス操作。
- Search・Command・リンク選択パネル・IME変換中のツリー操作。既存の入力を妨げない具体的な受付範囲を決める。
- `Ctrl+W`の後のEsc・待ち時間超過・無効キー、待機中のモード／フォーカス変更、Ctrlを押したままの2打目の扱い。
- 並び順、隠し属性・`.git`内部などの除外、壊れたリンクの表示、一覧更新・再試行操作、部分表示・表示上限、ルートの確認失敗時の表示。

## 受け入れ条件

未決定の操作・設定は確定後に具体的な確認手順を補う。以下のチェック項目は実施結果を示すものではない。

- [ ] ツリーを表示／非表示にでき、フォルダーを展開・折り畳みできる。
- [ ] 同じフォルダーにあるMarkdown、画像、PDF、ソース、拡張子なしのファイルを表示できる。
- [ ] ファイル行をクリック・ダブルクリック・Enterで操作してもファイルを開かず、表示中の文書と閲覧履歴を変更しない。
- [ ] Luaで起動時の表示／非表示を選べ、変更は再起動後に反映する。
- [ ] ツリー表示中に`Ctrl+W`→`h`でツリー、`Ctrl+W`→`l`で本文へ操作先を移せる。
- [ ] 別プロジェクトの文書を正常に開いた後にルートが追従し、読み込み失敗では元の文書とルートを維持する。
- [ ] フォルダー展開時に直下の項目を確認でき、深い階層や大量の項目の表示準備を待つ間も本文と他の利用可能な箇所を操作できる。
- [ ] アクセスできない箇所は空ではなくエラーと分かり、他の枝と本文を利用できる。
- [ ] シンボリックリンク・ジャンクションの項目は表示されるが、リンク先は展開できない。
