# 本文検索

[全体像に戻る](../index.md)

## 目的と位置づけ

文書の本文を検索し、一致した記述へ移動できるようにします。

## 要件

### 基本の流れ

1. Normalモードで`/`を押し、Searchモードへ移る。入力は空から開始する。
2. 入力に応じて一致範囲を強調する。入力中はスクロールしない。
3. Enterで確定し、検索開始位置以降の最初の一致へ移動してNormalモードへ戻る。
4. Normalモードの`n`で次の一致へ、`N`で前の一致へ移動する。

### 検索対象と条件

- 整形後の表示テキストを対象とする。Markdown記法やリンク先URLを本文として検索しない。
- Mermaidの非表示ソースと図のラベルは検索対象に含めない。
- 大文字・小文字を区別するリテラル検索とし、重複しない一致を列挙する。
- ハイライト表示中は一致範囲を強調し、現在選択中の一致は他の一致と区別する。配色は[表示・配色設定](display-settings.md)で変更できる。
- 入力中の空の検索語は一致なしとする。

### 検索開始位置と循環

- 検索確定時の開始位置は、画面上端にかかっている表示ブロックの先頭とする。ブロックは段落や表などの単位であり、画面上端の文字位置ではない。
- 長い段落や表の途中までスクロールしている場合、そのブロック内の画面より上に隠れた一致を選ぶことがある。この動作を許容する。
- 開始位置以降に一致がなければ、文書先頭の一致へ循環する。
- `n` / `N`による移動も、末尾／先頭で循環する。

### 確定・取消と検索語の引き継ぎ

- 空入力のEnterでは直前の確定済み検索語を再利用する。直前の検索語がない場合は、その旨をメッセージ表示してNormalモードへ戻る。
- 一致がない場合は`No matches found`を表示してNormalモードへ戻る。直前の確定語もない場合は`No previous search query`とする。通知位置と保持状態は[画面と操作モード](viewer-ui.md#表示言語と通知)に従う。
- Escでは入力を破棄し、確定済み検索語と、検索開始前に選択していた一致を復元してNormalモードへ戻る。取消によるスクロールは行わない。
- 検索中に文書が置き換わった場合、取消時に古い文書の一致位置を適用しない。
- 確定済み検索語は再読み込み・別ファイルへの切り替え後も引き継ぎ、新しい本文で一致を更新する。この更新だけでは一致位置へ自動移動しない。同一ファイルへのCLI open・行移動では本文を置換しないため、一致範囲・現在選択・ハイライトの状態も保持する。
- Search中に自動更新、または外部CLIのファイル切り替え・履歴移動で文書が置き換わった場合は、Searchモードと入力中の文字列を維持し、確定済み検索語ではなく編集中の検索語で新しい本文の一致を更新する。一致への自動移動は行わない。
- SearchモードではキーボードのNormal専用操作を実行しない。外部CLIによるスクロールや履歴移動は受け付ける。詳細は[外部操作](external-control.md#入力モードとの関係)、IME未確定中のEnterの扱いは[画面と操作モード](viewer-ui.md)を参照する。

### ハイライトの解除と再表示

- Commandモードで`:nohlsearch`または別名の`:noh`を実行すると、現在選択中の一致を含め、すべての検索ハイライトを消してNormalモードへ戻る。
- 確定済み検索語、一致範囲、現在選択中の一致は保持し、解除によるスクロールは行わない。
- 解除後の`n` / `N`では、保持している検索結果の次／前へ移動し、ハイライトを再表示する。
- 新しい検索では、入力中からハイライトを表示する。Escで取り消した場合は、検索開始前のハイライトの表示／非表示状態に戻す。
- 再読み込み・ファイル切り替えで一致を更新しても、解除状態は維持する。ただし、Searchモードでは編集中の検索語のハイライト表示を維持する。
- 検索していない状態で解除コマンドを実行しても、エラーにせず何もしない。

## 受け入れ条件

- [ ] 入力中は表示位置を動かさず一致を強調し、確定時に表示ブロック基準で一致へ移動する。
- [ ] 空入力の確定による検索語の再利用、Escによる取消、端での循環ができる。
- [ ] 再読み込み・ファイル切り替え後も検索語を引き継ぐが、古い一致位置への移動や自動スクロールは起きない。
- [ ] `:noh`と`:nohlsearch`で、検索状態とスクロール位置を維持したまま、すべての検索ハイライトを消せる。検索していなくてもエラーにならない。
- [ ] 解除後の`n` / `N`で移動と再表示ができ、新しい検索をEscで取り消すと、検索開始前の表示／非表示状態に戻る。
- [ ] 解除後に再読み込み・ファイル切り替えをしても、ハイライトは非表示のままとなる。
