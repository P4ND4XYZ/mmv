# my-markdown-viewer 要求・要件

## 利用の流れ

必要に応じて、ユーザー単位のLua設定ファイルで本文領域の配置・最大幅、配色、ファイルツリーの初期表示状態とルート判定マーカーを指定し、ビューアーを起動する。これらの設定変更はビューアーの再起動で反映する。具体的なAPI契約は[表示・配色設定](features/display-settings.md)に従う。

1. CLIの`mmv open FILE`（省略形は`mmv FILE`）で、Markdownファイルを指定して開く。同じファイルへのopenでは再読み込みしない。外部アプリから`mmv open FILE --line N`を送ると、保存済みソースの1始まりの指定行に対応する箇所を表示できる。同じ文書への行移動では本文や入力を置き換えず、履歴を増やさない。
2. 設定した配置・幅・配色で本文を表示し、未生成のMermaid図はバックグラウンドで生成する。図の生成完了を待たずに本文を読み始められる。
3. NormalモードでVimライクなキー操作によるスクロールを行い、Searchモードで本文を検索する。検索ハイライトは`:noh`で解除できる。リンクはマウスクリック、または`f`で開くリンク選択パネルからたどる。
4. Markdownファイルが保存されたら自動更新する。更新前のスクロール距離を維持する。ただし未適用の外部行指定は更新後の本文へ引き継ぎ、一度適用した指定は復活させない。文章の追加・削除後に同じ段落を保つことは保証しない。
5. Markdownへのリンクや見出しリンクをたどり、履歴の「戻る／進む」で移動前後の閲覧位置へ戻れる。
6. 必要に応じてファイルツリーを表示し、本文とフォーカスを行き来しながらフォルダー・ファイル構成を確認する。通常のMarkdownをEnter／`l`で開き、成功後は本文へフォーカスを移して閲覧を続ける。

## 対象範囲と制約

- 対象OSはWindows。Linux対応の優先度は低く、対象には含めない。
- 読み取り専用とする。
- アプリが生成するGUI文言は英語とする。Markdown本文、名前・パス、利用者の入力は翻訳しない。通知の正本は[画面と操作モード](features/viewer-ui.md#表示言語と通知)にまとめる。
- 別のファイルを開いた場合は、現在の表示を置き換える。
- 起動時や外部アプリから任意のファイルを開く入口はコマンドラインとする。
- 画面は左ツリー・右本文の固定2領域のpaneとし、任意分割・複数本文・汎用paneプラグインは対象外とする。
- Lua設定は表示・配色とツリー設定を対象とし、キーマップ・独自コマンドの登録やNeovim用カラースキームとの互換性は対象外とする。
- 再読み込みやMermaid図の後付け表示で、文書の内容を基準に読んでいた箇所を復元する処理は対象外とする。外部から指定されたソース行番号は一度限りの位置移動として扱い、適用後の再読み込みや寸法変更では再適用しない。再読み込み時のスクロール距離の維持と、履歴移動時の閲覧位置復元は対象に含める。

| 機能 | 利用上の役割 | 要件 |
