# my-markdown-viewer 要求・要件

## 利用の流れ

必要に応じて、ユーザー単位のLua設定ファイルで本文領域の配置・最大幅、配色、ファイルツリーの初期表示状態を指定し、ビューアーを起動する。設定変更はビューアーの再起動で反映する。

1. CLIの`mmv open FILE`（省略形は`mmv FILE`）で、Markdownファイルを指定して開く。
2. 設定した配置・幅・配色で本文を表示し、未生成のMermaid図はバックグラウンドで生成する。図の生成完了を待たずに本文を読み始められる。
3. NormalモードでVimライクなキー操作によるスクロールを行い、Searchモードで本文を検索する。検索ハイライトは`:noh`で解除できる。リンクはマウスクリック、または`f`で開くリンク選択パネルからたどる。
4. Markdownファイルが保存されたら自動更新する。更新前のスクロール距離を維持するが、文章の追加・削除後に同じ段落を保つことは保証しない。
5. Markdownへのリンクや見出しリンクをたどり、履歴の「戻る／進む」で移動前後の閲覧位置へ戻れる。
6. 必要に応じてファイルツリーを表示し、本文とフォーカスを行き来しながらフォルダー・ファイル構成を確認する。初期版ではツリーからファイルを開かない。

## 対象範囲と制約

- 対象OSはWindows。Linux対応の優先度は低く、対象には含めない。
- 読み取り専用とする。
- 別のファイルを開いた場合は、現在の表示を置き換える。
- 起動時や外部アプリから任意のファイルを開く入口はコマンドラインとする。
- Lua設定は今回は表示・配色専用とし、キーマップ・独自コマンドの登録やNeovim用カラースキームとの互換性は対象外とする。
- 再読み込みやMermaid図の後付け表示で、文書の内容を基準に読んでいた箇所を復元する処理は対象外とする。再読み込み時のスクロール距離の維持と、履歴移動時の閲覧位置復元は対象に含める。
