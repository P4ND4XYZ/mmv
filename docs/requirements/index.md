# my-markdown-viewer 要求・要件

## この文書について

目的、対象範囲、会話で合意した振る舞いを整理します。機能ごとの要件は各機能の文書に、実装方式の合意・候補と技術調査は[技術方針と採用前の検証](../research/technology-assessment.md)に分けて記録します。

- 全体像・機能範囲：合意済み。
- 個別の振る舞い：各機能の文書に記載した範囲は合意済み。
- 詳細仕様：実装に必要なすべての操作詳細・異常系まで確定したものではありません。文書にない振る舞いを、実装側の裁量で合意済みとして扱いません。

## 目的と利用場面

Windows上でMarkdownを手早く開き、キーボード中心で閲覧できる、シンプルな読み取り専用ビューアーを作ります。

利用場面は次の両方です。

- READMEや設計書など、既存のMarkdownファイルを単独で読む。
- Neovimなどで編集中のMarkdownファイルを、別ウィンドウでプレビューする。

利用者が重視する品質は起動の速さです。

## 利用の流れ

1. コマンドラインからローカルのMarkdownファイルを指定して開く。
2. 本文を表示し、未生成のMermaid図はバックグラウンドで生成する。図の生成完了を待たずに本文を読み始められる。
3. Vimライクなキー操作でスクロールし、本文検索やリンク選択を使って読み進める。
4. Markdownファイルが保存されたら自動更新する。更新前に読んでいた箇所を保つ。
5. ローカルMarkdownへのリンクや見出しリンクをたどり、履歴の「戻る／進む」で移動前後の閲覧位置へ戻れる。
6. Neovimなどから操作するときは、外部アプリにフォーカスを残したまま表示を変更する。

## 対象範囲と制約

- Rustで作成する。
- 対象OSはWindows。Linux対応の優先度は低く、対象には含めない。
- 読み取り専用とし、Markdownファイルの編集・保存は行わない。
- 単一起動とし、1ウィンドウで1ファイルを表示する。
- 別のファイルを開いた場合は、現在の表示を置き換える。タブや複数ウィンドウは設けない。
- ファイルを開く入口はコマンドラインとする。
- Neovimの未保存バッファを表示するのではなく、保存されたファイルを自動更新する。

## 品質要件

- 起動の速さを重視する。起動時間の数値基準は合意していない。
- 起動および本文表示を、Mermaid図の生成完了待ちで遅らせない。

調査結果、合意した技術方針、採用判断の状態は[技術方針と採用前の検証](../research/technology-assessment.md)を参照する。
