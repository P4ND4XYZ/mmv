# my-markdown-viewer 要求・要件

## 利用の流れ

1. CLIの`mmv open FILE`（省略形は`mmv FILE`）で、ローカルのMarkdownファイルを指定して開く。
2. 本文を表示し、未生成のMermaid図はバックグラウンドで生成する。図の生成完了を待たずに本文を読み始められる。
3. NormalモードでVimライクなキー操作によるスクロールを行い、Searchモードで本文を検索する。リンクはマウスクリック、または`f`で開くリンク選択パネルからたどる。
4. Markdownファイルが保存されたら自動更新する。更新前のスクロール距離を維持するが、文章の追加・削除後に同じ段落を保つことは保証しない。
5. ローカルMarkdownへのリンクや見出しリンクをたどり、履歴の「戻る／進む」で移動前後の閲覧位置へ戻れる。
6. Neovimなどから操作するときは、外部アプリにフォーカスを残したまま表示を変更する。

## 対象範囲と制約

- Rustで作成する。
- 対象OSはWindows。Linux対応の優先度は低く、対象には含めない。
- 読み取り専用とし、Markdownファイルの編集・保存は行わない。
- 単一起動とし、1ウィンドウで1ファイルを表示する。
- 別のファイルを開いた場合は、現在の表示を置き換える。タブや複数ウィンドウは設けない。
- 起動時や外部アプリから任意のファイルを開く入口はコマンドラインとする。表示中の文書内のリンクは、マウスクリックまたはキーボードのリンク選択パネルから開ける。アプリ内のパス入力やディレクトリ全体のファイル検索は対象外とする。
- Neovimの未保存バッファを表示するのではなく、保存されたファイルを自動更新する。
- Vimium風の文字ラベルによるリンク選択は対象外とする。
- 再読み込みやMermaid図の後付け表示で、文書の内容を基準に読んでいた箇所を復元する処理は対象外とする。再読み込み時のスクロール距離の維持と、履歴移動時の閲覧位置復元は対象に含める。
