# 検証計画

[検証サンプルの全体像](index.md)

## 状態と目的

V-01・V-02向けの初期実装があり、自動チェックとWindowsでのDebug起動・終了を確認しています。目視による描画品質の検証は未実施です。この文書は試験計画です。実装範囲と操作は[初期サンプルの実行](running.md)、実施したチェックと未検証の範囲は[初期実装の検証結果](results-initial.md)を参照してください。

GPUIとgpui-componentの採用可否を判断できるよう、実現できたこと、標準APIの制約、必要な追加処理、実測値を分けて記録します。製品全体の受け入れ試験を代替するものではありません。

## 検証の進め方

1. Windowsの開発環境と、互換性のある依存バージョンを確認し、最小ウィンドウを表示する。
2. 日本語と必要なMarkdown要素を描画する。
3. 採用判断への影響が大きい、リンクの位置取得と閲覧位置保持を早めに試す。
4. 検索・強調・一致位置への移動、文字ラベルによるリンク選択を確認する。
5. Mermaidを非同期生成して後から表示し、閲覧位置への影響を確認する。
6. Releaseビルドで起動時間を計測し、追加実装の必要性と合わせて採用判断を整理する。

依存APIの不足が見つかった場合は、製品要件を変更せず、制約と代替案を報告します。製品全体の実装やライブラリの大幅な独自改修へ、そのまま範囲を広げません。

## 検証項目

### V-01 基本描画

- [ ] 日本語、見出し、段落、箇条書き、引用、リンク、表、チェックリスト、コードブロックを表示する。
- [ ] シンタックスハイライトが有効になる構成と言語を記録する。
- [ ] 文書基準のローカル画像とWeb画像を表示する。
- [ ] 必要な設定、追加処理、未対応要素を記録する。

### V-02 検索と一致位置への移動

- [x] 整形後の表示テキストを取得し、ソースとの違いを確認する（GPUI結合テスト）。
- [x] 日本語と複数回出現する同じ文字列を検索し、目的の出現箇所を区別する（GPUI結合テスト）。
- [ ] 一致範囲を強調し、画面外の一致を画面内へ移動する。
- [ ] 改行・折り返しを含む表示で、範囲と描画の対応を確認する。

検索条件の細部や完成版の検索UIは確定しません。サンプルが使用した条件は試験条件として記録します。

### V-03 Vimium風リンク選択

- [ ] 表示中のリンクと、その画面上の位置を取得する。
- [ ] リンクへ文字ラベルを重ね、対応するリンクを選択する。
- [ ] 折り返されたリンク、スクロール後、ウィンドウサイズ変更後の位置を確認する。
- [ ] 標準APIだけで実現できる範囲と、追加実装が必要な範囲を区別する。

履歴管理や、製品全体のリンク処理の完成は対象にしません。

### V-04 閲覧位置保持

- [ ] 文書中ほどを表示した状態で、その前方へ文章を追加し、再表示する。
- [ ] 同じ段落付近を表示し続けられるか確認する。
- [ ] 文書内の位置と画面上の位置を対応付けるために必要な情報を記録する。
- [ ] 標準APIでは保持できない条件があれば、その条件を記録する。

読んでいた箇所自体を削除した場合の製品上の振る舞いは、この検証で勝手に確定しません。

### V-05 Mermaidの組み込み

- [ ] mermaid-cliでフローチャート、クラス図、ER図を生成し、日本語ラベルを含めて表示する。
- [ ] 生成中も本文を表示し、操作できることを確認する。
- [ ] 図を後から表示しても、読んでいた箇所を保てるか確認する。
- [ ] 文書や図を切り替えた後に、古い生成結果を現在の表示へ適用しないことを確認する。
- [ ] 生成失敗時に原因を取得でき、本文は表示し続けられることを確認する。

永続キャッシュとログ管理の仕組み全体は対象外です。製品で必要なキャッシュ・非表示・ログの方針は[製品のMermaid要件](../../../requirements/features/mermaid.md)で管理します。

### V-06 起動時間

- [ ] WindowsのReleaseビルドで、プロセス起動から本文が最初に表示されるまでを計測する。
- [ ] Mermaid生成完了までの時間を、本文表示までの時間と分ける。
- [ ] 初回と繰り返し起動の結果を、画像・図の生成状態やキャッシュ条件とともに記録する。
- [ ] 計測対象の文書、起点・終点の測り方、実行環境を記録する。

数値目標は合意されていません。実測結果を提示し、許容できるか判断します。サンプルの値をそのまま製品の起動時間保証にはしません。

## テストの分担

| 層 | 方法 |
|---|---|
| core | 文字列や値を入力する単体テスト。GUIや外部プロセスを起動しない |
| app | 操作・完了通知を入力し、状態と要求を確認する。古い結果の到着順も確認する |
| infra | 一時ファイルや実際のmermaid-cliを使う結合テスト |
| ui | GPUIとの結合テストとWindowsでの実機確認。座標、強調、スクロール、描画結果を確認する |
| 起動時間 | Releaseビルドを実測する |

実ツールがない場合、実ツールを使う試験は未実施と記録します。ダミーの結果による状態更新テストが成功しても、実際の図生成が成功したことにはしません。

## 結果として残す情報

検証実施後、各項目にV-01からV-06の識別子を付けて結果を記録します。

- 使用したソースのリビジョン、Rust・依存ライブラリ・mermaid-cliのバージョン。
- Windows、CPU、メモリ、GPUなどの実行環境とビルド設定。
- 再現できる入力文書、実行コマンド、操作手順、試験条件。
- 実際の結果と証拠。必要に応じてスクリーンショットや計測値。
- 標準APIで実現した部分、追加実装した部分、未対応・未検証の部分。
- 採用を妨げる制約と、回避策を採った場合の影響。

結果がない段階で、成功や採用決定を記録しません。
